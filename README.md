# SubtitleCurtain · 字幕遮挡器

免费、开源、只在本机运行的 Manifest V3 浏览器扩展。用可移动遮挡条盖住视频里的中文字幕，让注意力回到英语。无需账号、服务器、API 或订阅。

## 安装（免费，无需扩展商店）

1. 从 [GitHub Releases](https://github.com/KIMMMMY112/SubtitleCurtain/releases/latest) 下载 `SubtitleCurtain-Chromium-v0.1.0.zip`。
2. **先解压 ZIP**，保留整个文件夹。可打开 `START-HERE.html` 阅读安装说明；不要直接打开 `src/popup/popup.html`。
3. 打开浏览器扩展管理页，开启「开发者模式」，点击「加载已解压的扩展程序」，选择**直接包含 `manifest.json` 的文件夹**。
4. 刷新已打开的视频网页，点击工具栏上的 SubtitleCurtain 图标，打开「显示遮挡条」。可在浏览器的扩展菜单中将图标固定到工具栏。

| 浏览器 | 扩展管理页 |
| --- | --- |
| Chrome | `chrome://extensions` |
| Edge | `edge://extensions` |
| Brave | `brave://extensions` |
| Opera | `opera://extensions` |

四款浏览器共用同一份源码和安装包。实际测试的浏览器、版本、环境与网站范围以 [测试记录](docs/TEST-REPORT.md) 为准。v0.1.0 最低声明 Chromium 120；未把所有历史版本列为已验证。

这是一份开发者模式安装包，不能在 Chrome 中把 ZIP 当作扩展直接安装，也没有付费商店发布。请保留解压后的文件夹；更新时替换该文件夹内容，在扩展页点击「重新加载」，再刷新视频网页。开发者模式可能显示浏览器提醒。删除扩展会删除它的本地数据，先导出花色库。

## 使用

- **显示 / 隐藏**：弹窗中的开关，或网页中 `Alt + Shift + S`。隐藏后再显示会恢复之前的配置。首次安装默认隐藏，避免自动遮住所有网页。
- **移动**：解锁后用鼠标拖动遮挡条任意位置。
- **尺寸**：拖动右下角手柄，或在设置中调宽度与高度。宽度为窗口比例（2–100%，可见最小宽度 96 px），高度 16–400 px；窗口更小时自动限制在窗口内。
- **外观**：纯色、双色渐变、斜条纹、圆点、棋盘格、波纹；可调整两种颜色、渐变/条纹角度、花纹间距、10–100% 不透明度。
- **形状**：矩形、可调圆角、胶囊、椭圆、票据切角、自定义多边形。选择多边形后输入 3–24 个 `x,y` 百分比坐标，例如 `0,50 10,0 90,0 100,50 90,100 10,100`。圆角半径作用于「自定义圆角」形状。透明度或形状边缘可能露出字幕，完整遮挡时使用 100% 不透明矩形。
- **锁定位置**：打开锁定后，整个遮挡区域及手柄均不接收鼠标事件，播放器仍能接收其下方的点击。用设置或 `Alt + Shift + L` 解锁。
- **精确调整**：点击解锁的遮挡条获得焦点，方向键移动 1 px；加 Shift 移动 10 px；Ctrl / Command + 方向键改变尺寸。输入框、文本编辑器中的快捷键不被拦截。
- **管理形状 / 花色**：点击「打开形状 / 花色管理窗口」。编辑外观后输入名称，另存为花色；可应用、更新、重命名、删除，最多 50 个。应用花色不会改变位置、尺寸、锁定和显示状态。通过 JSON 导入 / 导出备份和分享，导入时按 ID 合并，同 ID 更新，文件上限 128 KB。
- **自动保存**：每个网站按主机名保存位置、大小、开关、锁定及样式；同主机名的页面和标签共用配置，不同主机名分开。嵌入式播放器跟随顶层网页的配置。花色库在本浏览器内跨网站共用，不上传、不自动跨设备同步。拖动或缩放在松开鼠标时保存。
- **重置**：恢复当前网站的默认值，并隐藏遮挡条；不删除花色库。

管理窗口关联打开它的视频标签页。关闭该视频标签后，重新从另一个视频页面打开设置。

## 全屏与限制

支持普通网页、通过 Fullscreen API 进入全屏的网页播放器容器，以及允许全屏的 http/https 跨域 iframe 播放器。全屏后通过快捷键开关、锁定；退出全屏后也可通过扩展弹窗修改。位置按当前窗口比例计算，全屏后可重新调整，并自动保存。同站所有标签会共享更改。

直接对 `<video>` 元素启用的浏览器原生全屏单独记录：顶层遮挡和快捷键按实际浏览器结果列出；原生全屏可能限制遮挡层的鼠标命中，因此不承诺在该模式内拖动或缩放。请在进入原生全屏前定位，或使用网站提供的播放器容器全屏。

浏览器内部页面、扩展商店等禁止注入的页面、独立画中画窗口、操作系统原生视频窗口不支持。DRM、特殊播放器、关闭站点访问权限、扩展被网站干预、受限制或不匹配的 iframe 可能影响使用。Safari、Firefox、iPhone/iPad、桌面悬浮窗尚未实现。**没有将未实测的视频网站宣称为兼容通过。**

如果安装后没有遮挡条，先刷新网页，确认扩展的站点访问已允许，再检查弹窗的显示开关。全屏中可用 `Alt + Shift + S`，macOS 上 Alt 对应 Option。锁定后无法拖动是预期行为。

## 开发与验证

需要 Node.js 22.13+、npm，以及可用的 Chromium 系浏览器。macOS 默认测试已安装的 Google Chrome；其他系统默认测试 Puppeteer 下载的 Chrome for Testing。测试使用临时浏览器配置文件，不读写日常浏览器资料。

```sh
npm ci
npm run check        # ESLint、Manifest/权限/本地运行检查、单元测试
npm run test:browser # 安装真实扩展，实际视频播放和交互/全屏验收
npm run package      # dist/unpacked + ZIP + SHA256SUMS.txt
```

测试其他浏览器：

```sh
SC_BROWSER_EXECUTABLE='/absolute/path/to/browser' SC_BROWSER_LABEL='Brave' npm run test:browser
```

`HEADLESS=1` 可用于 CI；测试记录会分别注明有界面和无界面运行方式。`SC_EXTENSION_DIR=/absolute/path/to/unpacked` 可验收解压后的发布包。结果和截图写入 `test-results/`。源代码仅依赖浏览器 API；npm 包均为开发依赖，不包含在安装 ZIP 中。

架构：`src/core/core.js` 提供数据校验、几何与样式；`src/core/overlay.js` 提供无 Chrome API 的 DOM 渲染和交互；`src/extension/` 提供 MV3 存储/消息适配器；`src/popup/` 提供控制与花色管理。未来 Safari 用户脚本可复用核心，替换存储和消息适配器；本版不包含或承诺已经测试该移植。

## 隐私与开源

仅请求 `storage` 和 `activeTab` 权限。http/https 页面中运行内容脚本以绘制遮挡层并支持 iframe 全屏；不读取视频内容、字幕或账号信息，不发出网络请求，无追踪、遥测或广告。详见 [隐私说明](PRIVACY.md)。
