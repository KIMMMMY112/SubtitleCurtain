## 真实 Mac Safari

Safari 18.1（20619.2.8.11.10），macOS 15.1，Userscripts 4.8.6 (136)。使用 Userscripts 实际注入，未用 GM 存储桩代替；通过原生 Safari 界面执行并读取本地验收页的 DOM 状态摘要。

实际观察：

- 视频播放中，video 尺寸 960×540，播放时间推进（MediaStream 在 Safari 的时间基数可能很大，不把绝对值当视频长度）。
- 遮挡条显示；显示→隐藏→恢复后保留尺寸。
- 方向键使 X 坐标 158→159；Command + Down 使高度 66→67；Command + Right 使宽度 1054→1055。
- 补测真实鼠标拖动：位置从 106,476 变为 126,456，尺寸保持 1099×97；拖动右下角手柄后尺寸变为 1119×107，位置保持 126,456。
- 刷新前后观察到位置 159,616 与尺寸 1054×67 一致。之后切换全屏/窗口布局时位置按视口比例变化，不要求绝对像素始终相同。
- 在设置中启用锁定后点击遮挡区域，底层播放器指针计数由 13 变为 14，视频按钮从“暂停”变为“播放”，证明该次点击穿透并暂停了视频；不把这次本地播放器结果扩大为所有网站操作通过。
- 播放器容器进入 Fullscreen API 后，视频、遮挡条及控制按钮都在真实 Safari 全屏中可见；全屏内 Alt + Shift + S 能隐藏遮挡；Escape 后恢复网页并能再次显示。
- 外观选择“渐变”后面板显示已保存；花色“Safari验收临时花色”保存、重命名、删除均返回对应状态，删除后列表恢复空选择。

这些记录证明列出的动作，不宣称已经完成所有 Safari 网站、所有输入方式、JSON 文件对话框或原生视频全屏组合。用户也已反馈 Mac Safari 可以使用。
