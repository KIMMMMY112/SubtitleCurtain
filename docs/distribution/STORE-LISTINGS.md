## English short description

Hide translated subtitles with a movable, customizable curtain for focused language practice.

## English full description

SubtitleCurtain puts a movable curtain over part of a video webpage. Position it over translated subtitles while keeping the original language visible, so you can choose when to look at a translation during listening practice.

You place the curtain yourself. SubtitleCurtain does not recognize subtitle text, generate translations, or remove a video's subtitle track.

Features:

- Show or hide the curtain with one switch.
- Drag it into position and resize it with the corner handle or width and height controls.
- Choose solid colors, gradients, stripes, dots, checkerboards or waves.
- Adjust colors, opacity, rounded corners and shapes, including a custom polygon.
- Lock the position so clicks can reach the video player underneath.
- Restore your position, size and appearance after refreshing the webpage.
- Save, apply, rename, update and delete appearance presets; back them up with JSON import and export.
- Use keyboard shortcuts and fine position adjustments.

Preferences are stored locally by website hostname. Appearance presets are shared across sites in this browser profile. The extension does not send those settings to the developer. It has no account system, advertising, analytics, paid API or subscription. The current site's hostname is used locally to select its saved configuration; see the privacy policy for the full data description.

Use ordinary webpage playback or a supported player-container fullscreen mode. Browser internal pages, extension stores, picture-in-picture and operating-system video windows cannot be covered. Direct native video fullscreen may restrict mouse editing; position the curtain before entering that mode or use the website's player-container fullscreen. Changes in video layout can require repositioning.

After installing, refresh an already-open video page, click the extension icon, then enable Show curtain. The curtain starts hidden. Use an opaque rectangle when you need to fully cover a line of text.

SubtitleCurtain is free and open source under the MIT License. Source code, installation help and the actual browser test records are available in the project repository. Compatibility is limited to the documented tested environments; the extension does not promise to work on every video website.

## 中文完整介绍

SubtitleCurtain 是免费、开源的字幕遮挡器。它在视频网页上显示一个可以移动的遮挡条，由你把它放到中文字幕或其他翻译字幕上方，保留英文等原文内容，方便自主进行听力练习。

遮挡位置需要手动调整。本扩展不会识别字幕、生成翻译，也不会修改视频原有的字幕轨道。

主要功能：

- 一键显示、隐藏，再次显示时保留原来的配置。
- 用鼠标自由拖动；拖动右下角手柄，或用宽高设置调整尺寸。
- 支持纯色、渐变、斜条纹、圆点、棋盘格和波纹。
- 自定义颜色、不透明度、圆角和形状，包括多边形顶点。
- 锁定位置后，让点击穿透遮挡区域，继续操作下方播放器。
- 刷新网页后恢复位置、大小、外观、显示状态和锁定状态。
- 保存、应用、重命名、更新、删除形状花色，并通过 JSON 导入导出备份。
- 支持快捷键及键盘精确微调。

设置按网站主机名保存在当前浏览器本地，花色库在本浏览器配置内跨网站共用。扩展不向开发者发送这些设置，没有账号系统、广告、统计追踪、付费 API 或订阅。当前网站主机名用于选择本地保存的配置，完整数据说明请阅读隐私政策。

请使用普通网页播放或支持的播放器容器全屏。浏览器内部页面、扩展商店、画中画和系统原生视频窗口无法遮挡；直接对 video 元素进入原生全屏时，鼠标编辑可能受限，可提前定位或使用网站提供的播放器容器全屏。视频布局变化后可能需要重新调整位置。

安装后，先刷新已经打开的视频网页，再点扩展图标并开启“显示遮挡条”。首次安装默认隐藏。需要完整遮住一行文字时，建议使用 100% 不透明矩形。
